Research

Conference paper · submitted 2026

Stress-Adaptive LLM Conversational Assistance Based on Wearable Sensing

Introduces PulseMind, a system in which a Galaxy Watch derives heart-rate-variability features, classifies the wearer's autonomic state, and passes that state to a locally hosted LLM. When the wearer is stressed, the assistant changes how it answers.

PulseMind-Pair

Ongoing extension: two people, two watches, one assistant that shares the load.

Galaxy Watch 8Heart rate, RMSSD, skin conductance and motion, sent every 60 seconds
➜
Relay serverCompares each user to a personal baseline and decides calm or stressed
➜
Local LLMLLaMA 3 on Ollama adapts length and tone of every reply
  • Stress is flagged only when two of three signals shift for two windows in a row, which keeps false alarms low.
  • When one partner is stressed, their waiting task can be offered to the calm partner, with limits and a cooldown so nobody is overloaded.
  • Everything runs on a local GPU machine, so physiological data never leaves the lab.
  • Built end to end: Wear OS app in Kotlin, Python relay with PIN login and team mode, browser interface, automated tests and a study-log export for analysis.
